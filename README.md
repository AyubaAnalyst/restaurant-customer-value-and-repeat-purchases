Restaurant Customer & Sales Analysis

Project Overview

This project uses SQL and Microsoft Excel to analyse restaurant sales, customer purchasing behaviour, cuisine performance, and repeat purchases. The goal is to identify valuable customers and opportunities to improve customer retention and revenue.

Tools Used

- MySQL: Data cleaning, validation, joins, exploratory data analysis (EDA), and business analysis.
- Microsoft Excel: PivotTables, KPI cards, charts, and dashboard creation.

Key Insights

- Customer retention: 1,272 of 1,452 customers were repeat customers, representing 87.6%.
- Customer value: Repeat customers generated approximately $425 in average revenue per customer, compared with $112 for one-time customers.
- Cuisine performance: Thai cuisine generated the highest revenue ($127,429) and repeat-customer rate (31.5%).
- Growth opportunity: Chinese cuisine recorded the lowest revenue ($59,562) and repeat-customer rate (18.2%).

Recommendations

- Encourage one-time customers to make repeat purchases through targeted offers.
- Test loyalty programmes and personalised promotions.
- Investigate the factors behind differences in cuisine performance.
- Evaluate menu-item costs and profit margins before running promotions.

Deliverables

- SQL scripts for data cleaning, validation, EDA, and business analysis.
- Excel dashboard presenting key metrics and findings.
- Business Insights and Recommendations report.

Conclusion

This project demonstrates how SQL and Excel can be used together to transform business data into actionable insights that support customer retention and informed business decisions.
